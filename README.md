# Chrono Trigger Rando-Dalton Imperial for Archipelago

This project provides Archipelago integration for the Chrono Trigger Rando-Dalton Imperial randomizer.

## Rando-Dalton Imperial
Rando-Dalton Imperial is a highly customizable, open world randomizer for the SNES version of Chrono Trigger with a focus on retaining as much of the vanilla experience as possible. 

Some notable features include:
- Key item and character based gating
- An objective system where more completed objectives offers more paths to Lavos
- Dynamically scaled enemies to keep a smooth difficulty curve no matter where the seed takes you
- Highly customizable entrance randomization
- An enormous number of other options to custom tailor the experience you want

## Archipelago
Archipelago is a multiworld framework that allows players in multiple games to share randomized items across their worlds. This project is the plugin that allows players to experience Rando-Dalton Imperial through Archipelago.
